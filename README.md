# 🌟 WordAnime - Meu Blog de Animes

Seja bem-vindo ao **WordAnime**! Este é um projeto de um blog simples sobre a cultura pop japonesa, focado em animes e mangás. O site foi desenvolvido inteiramente por mim como um projeto prático para um trabalho escolar.

O objetivo principal foi aplicar conhecimentos básicos de estruturação web, estilização e interatividade dinâmica.

---

## 🚀 Funcionalidades

* **Design Limpo e Organizado:** Layout dividido em área principal de postagens e uma barra lateral (*sidebar*).
* **Menu de Navegação:** Links rápidos para as seções do blog (Início, Reviews, Notícias, Sobre Mim).
* **Botão de Gostei Interativo:** Um sistema feito em JavaScript que permite curtir e descurtir as postagens, atualizando o contador na tela em tempo real.
* **Totalmente Organizado:** Código componentizado e dividido de forma limpa em três arquivos separados.

---

## 📂 Estrutura do Projeto

O projeto está dividido nos seguintes arquivos:

* `index.html`: Toda a estrutura de texto, imagens e tags estruturais do blog.
* `style.css`: A folha de estilo responsável pelas cores (estilo vibrante inspirado em Shounen), fontes, espaçamentos e layout flexível (*Flexbox*).
* `script.js`: Toda a lógica por trás do botão de curtidas.

---

## 🛠️ Tecnologias Utilizadas

As seguintes tecnologias foram utilizadas no desenvolvimento deste projeto:

* [HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML) - Para a estruturação do conteúdo.
* [CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS) - Para a estilização e design visual.
* [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript) - Para a lógica de interação do usuário.

---

## 💻 Como Rodar o Projeto

Para visualizar o projeto no seu computador, siga os passos abaixo:

1. Baixe todos os arquivos deste repositório (`index.html`, `style.css` e `script.js`).
2. Coloque todos eles **juntos dentro da mesma pasta**.
3. Dê um duplo clique no arquivo `index.html`.
4. O blog abrirá automaticamente no seu navegador padrão!
